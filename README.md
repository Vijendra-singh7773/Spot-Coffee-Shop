# The Spot Coffee Shop — Website Demo

Responsive React + Vite cafe website concept.

## Run locally
1. Install Node.js (LTS).
2. Extract the ZIP and open the project folder in VS Code.
3. Run `npm install`, then `npm run dev`.
4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build
Run `npm run build`. The production site is generated in `dist/`.

## Content and imagery
- Menu names and visible DJF prices from the provided screenshots are included.
- Items without a visible price are marked “Ask” rather than assigned an invented price.
- The photos supplied in the chat have been removed. The demo uses curated remote Unsplash photo URLs, so internet access is required for those images to load.
- Business contact/location details are based on the listing supplied in the conversation.
- This is a demo concept, not an official website.
